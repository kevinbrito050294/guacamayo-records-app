 ANTES QUE NADA: 4 PASOS CLAVE (15 minutos)
═════════════════════════════════════════════════════════════════════════════

1️⃣  PERSONALIZA TU NÚMERO DE WHATSAPP
     ├─ Abre: src/components/Cart.tsx
     ├─ Buscá la constante telTienda (se arma al confirmar el pedido)
     ├─ Poné tu número: solo dígitos, con código de país, sin guiones ni espacios
     │  (ej: 5491123456789)
     └─ Guardá el archivo y después corré npm run build

2️⃣  IMPORTA DATOS DE PRUEBA
    ├─ Abre la web y haz clic en el engranaje ⚙️ (barra superior)
    ├─ Iniciá sesión con tu EMAIL y CONTRASEÑA de admin
    ├─ Ve a "Importar CSV"
    ├─ Sube el archivo: DATOS_EJEMPLO.csv
    └─ Haz clic "Importar 10 registros"

3️⃣  VERIFICA LAS TASAS
    ├─ En Admin, ve a "Tasas de Cambio"
    ├─ Mirá las dos tasas que ya están cargadas (ARS y USDT)
    ├─ Poné el Dólar Blue de HOY y hacé clic "Guardar"
    └─ ¡Listo! La tasa no viene de un valor fijo: la guardás vos en la base

4️⃣  (SOLO LA PRIMERA VEZ) ACTIVÁ EL ACCESO AL PANEL
    ├─ El panel pide email + contraseña: no hay contraseña única
    ├─ Corré las migraciones pendientes: npm run migrar
    │  (en Railway: shell del servicio MySQL, base "railway")
    │  Ojo: el checkout necesita TODAS las migraciones, no solo la de cuentas.
    │  Si arrancás de una base vacía, corré primero
    │  `node scripts/migrar.mjs --archivo 2026-09-29_pedidos_cupones.sql`
    │  y después `npm run migrar` (ver docs/COUPONS.md)
    ├─ Creá el usuario admin (mínimo 8 caracteres):
    │  $env:ADMIN_PASSWORD='mi-clave'; node scripts/crear-admin.mjs --email admin@guacamayorecords.com --nombre "Guacamayo"
    ├─ Volvé a correr el mismo comando si necesitás resetear la contraseña
    └─ Detalle: README.md → "🔐 Acceso y Cuentas"

 SI ALGO NO FUNCIONA
═════════════════════════════════════════════════════════════════════════════

❌ "No veo los vinilos"
   → Recarga la página (F5)
   → Importa DATOS_EJEMPLO.csv primero

❌ "WhatsApp no se abre"
   → Verifica que tengas WhatsApp instalado
   → Permite pop-ups en el navegador
   → Verifica la constante telTienda en src/components/Cart.tsx

❌ "No me deja entrar al panel"
   → El login pide EMAIL + contraseña (hay que tener usuario creado)
   → Corré las migraciones pendientes: npm run migrar
   → Creá o resetéala con scripts/crear-admin.mjs
   → Ver README.md → "🔐 Acceso y Cuentas"

❌ "El checkout no guarda el pedido / el panel no muestra los cupones"
   → Falta una migración: el server ya escribe cupon_id, cupon_codigo y
     descuento_aplicado, y si las columnas no existen, el pedido se cae
   → Corré `npm run migrar` y revisá `node scripts/migrar.mjs --estado`
   → Ver docs/COUPONS.md → "Migración y qué verificar"

❌ "El botón de Google no aparece"
   → Falta VITE_GOOGLE_CLIENT_ID en el .env, y su ausencia no tira ningún error
   → Tiene que ser EXACTAMENTE el mismo valor que GOOGLE_CLIENT_ID del server
   → Después de cambiarla: npm run build (las VITE_* se compilan)
   → Ver README.md → "🔐 Acceso y Cuentas"

❌ "El panel dice que ya está abierto en otro dispositivo"
   → La sesión del admin es única: cerrá la otra pestaña
   → Esperá 1 minuto y volvé a intentar

❌ "CSV no se importa"
   → Asegúrate de guardar como CSV (no XLSX)
   → No debe tener filas vacías
   → Ver MANUAL_OPERACIONES.md

❌ "Los precios están mal"
   → Ve a Admin → Tasas de Cambio
   → Actualiza el Dólar Blue
   → Recarga la página
